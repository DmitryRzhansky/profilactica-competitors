1240|## 6. Кодирование
1241|
1242|Хаб → форматы, методы, препараты, раскодирование.
1243|
1244|Любой метод/препарат → хаб кодирования + 3–5 альтернативных методов + парное `раскодирование от {тот же препарат}` (если есть) + `лечение алкоголизма` + `реабилитация` + `срыв после кодирования` + `цены` + профиль врача. Методные страницы не получают ГЕО-сетку.
1245|
1246|`Раскодирование` (хаб) → все дочерние `раскодирование от Эспераль / Аквилонг / Алгоминал / Дисульфирам / Налтрексон / Вивитрол / Торпедо` + хаб кодирования + `срыв после кодирования` + цены + врач.
1247|
1248|Каждая страница `раскодирование от X` → родитель `раскодирование` + парное `кодирование: X` + 2–3 соседних раскодирования по другим препаратам + `срыв после кодирования` + `лечение алкоголизма` + цены + врач. Без ГЕО-матрицы и без ссылок на все препараты сразу.
1249|
1250|ГЕО кодирования → общий хаб кодирования + другие acute-услуги этой локации; не ссылаться на десятки препаратов и не размножать раскодирование по метро/городам.
1251|
1252|## 7. Лечение алкоголизма
1253|
1254|Сегментные страницы (`женский`, `пивной`, `мужской`, `хронический`, `без кодирования`) → общий хаб + `стационар/амбулаторно` + `кодирование` + `реабилитация` + профиль врача. Между сегментными страницами максимум 2–4 действительно близких ссылки.
