## Визуальный стиль

Отчёт должен выглядеть как аналитический продукт, а не блоговая статья.

- Основной фон светлый.
- Основной акцент можно сохранить около `#1a7fc4`.
- Текст тёмный, высокий контраст.
- Максимальная ширина контента 1240–1360 px.
- Слева на desktop — sticky sidebar с разделами.
- На mobile — верхняя панель и выезжающее меню.
- Карточки без чрезмерных теней и градиентов.
- Таблицы плотные, но читаемые.
- P0/P1/P2 маркировать компактными badge.
- Не использовать десятки случайных цветов: для графиков единая палитра с 6–8 согласованными оттенками.

При сборке контента распознавать маркеры вида:


В финальном HTML **не должно остаться сырых PH-маркеров**.
