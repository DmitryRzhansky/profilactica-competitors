# План SEO-продвижения на 2 месяца

Основная задача первых двух месяцев - сначала полностью перестроить внутреннюю основу сайта, а затем перейти к его внешнему продвижению.

Работа строится в следующем порядке:

1. На первой неделе собираются исходные данные, коммерческая и географическая семантика, определяется будущая структура сайта.
2. На второй неделе сайт полностью переносится на новую самописную систему управления, создаются все запланированные коммерческие и географические страницы, настраивается техническая часть.
3. На третьей неделе отдельно прорабатывается информационное направление: собирается информационная семантика и формируется контент-план для дальнейшего развития самого сайта.
4. Начиная с четвертой недели основной упор переносится на внешнее продвижение: Яндекс Карты, профильные площадки, ссылки, упоминания, работа с репутацией, поведенческими факторами и анализ результатов.

---

# Первый месяц

## Неделя 1. Сбор исходных данных, семантики и проектирование структуры

### 1. Создание брифа-опросника

Перед составлением брифа анализируется текущий сайт, чтобы определить, каких данных не хватает для дальнейшей переработки проекта и какие сведения необходимо подтвердить.

После этого формируется бриф-опросник.

Полученные ответы используются при создании новых страниц и позволяют не переносить на новый сайт старые ошибки, противоречия и неподтвержденные данные.

На выходе:

- подготовленный и заполненный бриф;
- подтвержденные данные, которые можно использовать на сайте;
- фактическая основа для дальнейшей переработки сайта.

---

### 2. Сбор семантического ядра для коммерческих страниц

Проводится полный сбор коммерческих поисковых запросов по направлениям, связанным с услугами проекта.

Собирается реальный поисковый спрос, изучается текущая структура сайта и анализируется поисковая выдача. Уже после этого определяется, какие направления должны получать отдельные страницы, а какие запросы относятся к одной пользовательской задаче и должны объединяться.

Работа включает:

- сбор коммерческих поисковых запросов;
- расширение семантики через связанные формулировки;
- очистку нерелевантных запросов;
- отделение коммерческого спроса от информационного;
- проверку частотности;
- анализ поисковой выдачи;
- определение пользовательского намерения;
- объединение запросов с одинаковым намерением;
- разделение запросов, которые требуют разных страниц;
- поиск пересечений между существующими страницами;
- выявление недостающих коммерческих направлений;
- выявление страниц, которые конкурируют между собой;
- выявление страниц, которые фактически решают одну и ту же задачу пользователя;
- определение приоритетности будущих страниц.

На выходе:

- очищенное коммерческое семантическое ядро;
- разбивка запросов по группам;
- перечень необходимых коммерческих страниц;

---

### 3. Отдельный сбор географической семантики

Параллельно отдельно собирается поисковый спрос, в котором услуга связана с конкретной территорией.

Для каждого географического направления проверяется:

- частотность запросов;
- наличие отдельных локальных страниц в поисковой выдаче;

---
### 4. Подготовка таблицы 301-редиректов

Одновременно составляется таблица соответствия старых и новых адресов.

Для каждого изменяемого или удаляемого адреса фиксируется:

- текущий адрес;
- новый адрес;

---

### 5. Сохранение исходных показателей сайта

До начала переноса фиксируется текущее состояние проекта.

Фиксируется:

- поисковый трафик;
- внешние ссылки;
- количество страниц в индексе;

---

# Неделя 2. Полный перенос сайта на новую систему управления и создание страниц

Основная задача второй недели - полностью перенести проект на новую самописную систему управления сайтом и к концу недели получить готовый новый сайт со всей запланированной на первом этапе коммерческой структурой.

Перенос не растягивается: к окончанию второй недели новая версия должна быть собрана, основные технические настройки выполнены, а коммерческие и географические страницы - созданы.

---

### 1. Разработка новой системы управления сайтом

Создается новая система управления с учетом структуры, сформированной на первой неделе.

Она должна позволять без постоянного вмешательства разработчика:

- создавать и редактировать страницы;
- управлять блоками страниц;
- редактировать мета-теги;
- менять заголовки;
- управлять изображениями;
- создавать географические страницы;
- создавать страницы специалистов;
- создавать информационные материалы;
- управлять ценами и другими повторяющимися данными;

---

### 2. Создание шаблонов, виджетов и функциональных блоков

На основании структуры первой недели создаются шаблоны всех необходимых типов страниц.

Для каждого типа страницы определяется:

- какие блоки присутствуют обязательно;
- какие блоки выводятся при необходимости;
- какие поля редактируются отдельно;
- какие данные могут выводиться автоматически;
- какие данные задаются вручную;
- какие элементы связываются с другими разделами сайта.

---

### 3. Реализация технических SEO-настроек

В новой системе сразу реализуются основные возможности для поисковой оптимизации:

- редактирование Title;
- редактирование Description;
- редактирование H1;
- управление адресами страниц;
- robots;
- canonical;
- автоматическая карта сайта;
- хлебные крошки;
- корректные коды ответа;
- управление 301-редиректами;
- ALT для изображений;
- управление заголовками;
- микроразметка;
- дата публикации;
- дата обновления;
- возможность указывать автора;
- возможность указывать медицинскую проверку материала;
- управление внутренними ссылками;
- возможность редактировать основные SEO-поля без участия разработчика.

---

### 4. Перенос и создание служебных страниц

На новую систему переносятся и приводятся в порядок необходимые страницы о компании, специалистах, лицензиях, документах и другие служебные разделы.

Их окончательный состав определяется по итогам первой недели.

Задача - чтобы новая версия сайта сразу содержала актуальную и непротиворечивую информацию о клинике.

---

### 5. Создание всех запланированных коммерческих страниц

По семантическому ядру и структуре первой недели создаются все коммерческие страницы, которые были признаны необходимыми.

---

### 6. Создание всех отобранных географических страниц

Одновременно создается географическая структура, сформированная после анализа спроса.

Создаются только те страницы, которые были признаны целесообразными на первой неделе.

---

### 7. Настройка 301-редиректов

После создания новой структуры применяются подготовленные перенаправления.

Проверяется:

- все ли измененные старые адреса ведут на правильные новые страницы;
- нет ли цепочек перенаправлений;
- нет ли циклических редиректов;
- не остаются ли важные старые адреса с ошибкой 404.

---

### 8. Настройка внутренней перелинковки

В новой структуре сразу создаются связи между:

- основными коммерческими страницами;
- более узкими услугами;
- географическими страницами;
- страницами специалистов;
- служебными страницами;

---

### 9. Настройка аналитики

До окончательного запуска новой версии настраивается отслеживание основных действий:

- отправка форм;
- клики по телефону;
- переходы в мессенджеры;
- обратные звонки;
- другие целевые действия.

---

### 10. Полная техническая проверка после переноса

После запуска новой версии проверяются:

- доступность основных страниц;
- корректность 301-редиректов;
- отсутствие 404;
- robots;
- canonical;
- карта сайта;
- дубли;
- заголовки;
- мета-теги;
- внутренние ссылки;
- формы;
- события аналитики;
- мобильная версия;
- скорость загрузки;
- корректность кодов ответа;
- доступность сайта для поисковых роботов.

---

# Неделя 3. Сбор информационной семантики и формирование контент-плана для сайта

После завершения коммерческой части отдельно прорабатывается информационное направление.

Задача третьей недели - сформировать подробный план развития информационного раздела на следующие месяцы.

---

### 1. Анализ существующего информационного раздела

Сначала изучаются уже опубликованные материалы.

Для каждого определяется:

- получает ли он поисковый трафик;
- имеет ли показы и позиции;
- соответствует ли он реальному поисковому спросу;
- актуальна ли информация;
- пересекается ли он с другими материалами;
- можно ли его сохранить;
- нужно ли его переработать;
- нужно ли объединить его с другим материалом;
- есть ли смысл удалить страницу.

---

### 2. Сбор информационной семантики

Отдельно собираются информационные поисковые запросы по тематике проекта.

Работа включает:

- сбор поисковых запросов;
- расширение семантики;
- очистку нерелевантных формулировок;
- проверку частотности;
- группировку запросов;
- разделение разных пользовательских задач;
- поиск тем, которые уже закрыты существующими материалами;
- поиск недостающих тем.

---

### 3. Анализ информационной поисковой выдачи

Для перспективных групп запросов проверяется:

- какие типы страниц находятся в результатах;
- насколько сильны конкуренты;
- какие вопросы раскрываются;
- какие вопросы остаются без нормального ответа;
- имеет ли тема практическую ценность для проекта.

---

### 4. Определение приоритетности тем

Темы оцениваются по нескольким параметрам:

- величина спроса;
- близость пользователя к обращению в клинику;
- возможность связать материал с коммерческими страницами;
- потенциальная польза для внутренней перелинковки;
- соответствие направлениям клиники;
- возможность подготовить качественный экспертный материал;

---

### 5. Формирование контент-плана

Для каждого будущего материала фиксируется:

- тема;
- группа запросов;
- связанная коммерческая страница;
- страницы для внутренней перелинковки;
- решение по существующей статье, если такая уже есть.

---

# Неделя 4. Внешнее продвижение

### 1. Аудит Яндекс Карт и Яндекс Бизнеса

Проверяется:

- название;
- адрес;
- телефон;
- сайт;
- режим работы;
- категории;
- описание;
- услуги;
- фотографии;
- цены;
- отзывы;
- ссылки;
- полнота заполнения;
- соответствие информации данным нового сайта.

### 2. Переработка карточки организации

Проводится:

- корректировка данных;
- заполнение услуг;
- добавление и обновление фотографий;
- проверка категорий;
- актуализация описания;
- приведение цен и другой информации в соответствие с сайтом;
- проверка ссылок;
- заполнение доступных элементов карточки.

### 3. Работа с отзывами

Проверяются:

- количество отзывов;
- регулярность их появления;
- содержание;
- наличие ответов;
- негативные отзывы;

### 4. Аудит других внешних профилей

Проверяются существующие карточки и профили клиники на сторонних площадках.

Для каждой площадки оценивается:

- актуальность информации;
- наличие ссылки;
- правильность контактов;
- качество оформления;
- отзывы;
- возможность добавить услуги;
- возможность разместить специалистов;

---

# Неделя 5. Анализ ссылочного профиля и начало ссылочного продвижения

### 1. Анализ текущих внешних ссылок

Проверяется:

- какие сайты уже ссылаются;
- на какие страницы ведут ссылки;
- какие ссылки имеют ценность;
- какие выглядят сомнительно;

### 2. Анализ ссылочного продвижения конкурентов

Изучается:

- с каких сайтов конкуренты получают ссылки;
- какие типы площадок используют;
- на какие страницы чаще ведут ссылки;
- какие публикации получают упоминания;
- какие каталоги используются;
- какие медицинские и локальные ресурсы задействованы.
- анкоры.

### 3. Составление плана размещений

Для потенциальных размещений фиксируются:

- площадка;
- тип размещения;
- целевая страница;
- ориентировочная стоимость;
- тематичность;
- качество площадки.

### 4. Начало размещений

Начинается постепенное получение внешних ссылок и упоминаний на выбранных площадках.

---

# Неделя 6. Сторонние площадки и расширение присутствия бренда

### 1. Поиск профильных площадок

Подбираются:

- медицинские каталоги;
- площадки со специалистами;
- справочники;
- тематические порталы;
- локальные площадки;
- информационные проекты;
- площадки, страницы которых сами хорошо ранжируются в поиске.

### 2. Создание и доработка внешних страниц

Контролируются:

- название;
- контактные данные;
- описание;
- услуги;
- специалисты;
- ссылки;
- фотографии;
- отсутствие противоречий с основным сайтом.

### 3. Размещение внешних материалов

Рассматриваются:

- экспертные статьи;
- ответы специалистов;
- интервью;
- комментарии;
- тематические материалы;
- публикации, способные получать собственный поисковый трафик.

### 4. Дополнительное занятие поисковой выдачи

Ищутся запросы, по которым можно присутствовать одновременно собственным сайтом и страницами на внешних ресурсах.

---

# Неделя 7. Работа с поведенческими факторами и продолжение внешнего продвижения

### 1. Выбор страниц и запросов

Учитываются:

- текущие позиции;
- частотность;
- коммерческая ценность;
- наличие страницы в выдаче;
- стабильность позиции;
- достаточная релевантность страницы запросу.

### 2. Фиксация исходных показателей

Для выбранных запросов фиксируются:

- страница;
- запрос;
- исходная позиция;
- текущий органический трафик;

### 3. Проведение тестов

Работа проводится на ограниченной группе запросов, чтобы можно было отдельно оценивать изменения и не смешивать их с результатами ссылочного продвижения, переиндексации и переработки сайта.

### 4. Продолжение внешнего продвижения

Параллельно продолжаются:

- ссылочные размещения;
- работа с Яндекс Картами;
- работа с отзывами;
- заполнение внешних профилей;
- получение новых упоминаний;
- публикация материалов на сторонних ресурсах.

---

# Неделя 8. Анализ первых результатов и корректировка стратегии

### 1. Проверка технического состояния

Повторно проверяются:

- индексация;
- ошибки сканирования;
- старые адреса;
- 301-редиректы;
- дубли;
- страницы без внутренних ссылок;
- лишние индексируемые страницы;
- скорость загрузки;

### 2. Анализ позиций и поисковой видимости

Сравниваются:

- исходные позиции;
- текущие позиции;
- количество запросов в видимой части выдачи;
- новые запросы;
- страницы с ростом;
- страницы с падением;
- страницы, которые пока не получили видимости.

### 4. Анализ поискового трафика и обращений

Проверяется:

- какие страницы получают поисковый трафик;
- какие коммерческие направления растут;
- какие географические страницы получают показы;
- какие страницы потеряли трафик;
- какие страницы дают обращения;
- какие услуги дают больше заявок;

### 5. Анализ Яндекс Карт и внешних площадок

Проверяется:

- динамика показов карточки;
- переходы;
- звонки;
- новые отзывы;
- изменения видимости;
- эффективность внешних профилей;
- индексация опубликованных материалов.

### 6. Анализ ссылочного продвижения

Проверяется:

- какие ссылки размещены;
- какие проиндексированы;
- какие страницы получили усиление;
- какие площадки стоит использовать повторно;
- от каких размещений отказаться;
- как распределить ссылки на следующий период.

### 7. Анализ тестов с поведенческими факторами

Сравниваются:

- исходные и текущие позиции;
- стабильность изменений;
- поисковая посещаемость;
- обращения;
- целесообразность продолжения работы по выбранным запросам.

### 8. Корректировка контент-плана

По первым поисковым данным:

- добавляются обнаруженные запросы;
- убираются слабые направления;
- усиливаются перспективные группы;
- уточняется очередность публикации материалов.

### 9. Формирование плана на следующие 3-6 месяцев

Определяется:

- какие страницы усиливать;
- какие статьи публиковать далее;
- на какие страницы направлять новые ссылки;
- какие внешние площадки масштабировать;
- как продолжать работу с Яндекс Картами;
- какие запросы использовать для дальнейших тестов;
- какие технические задачи остаются;
- какие направления показывают наибольшую отдачу.
